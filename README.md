# Tonal Island mini-site

[Visit Tonal Island](https://fmhun.github.io/tonal-island-site/)

An interactive introduction to Tonal Island, a macOS companion for understanding the notes and intervals you play.

This repository contains the public static website. The application is developed separately. There is no public application download yet.

The demo includes ten musical excerpts, adapted from public-domain editions published by the Mutopia Project. Sound is synthesized locally in the browser. See [music credits](https://fmhun.github.io/tonal-island-site/music-credits.html).

GitHub Pages deploys only `site/`, using the workflow in `.github/workflows/pages.yml`, when changes are pushed to `main`.
