Tonal Island

Install Tonal Island

A public macOS download is being prepared. You can already try the interactive demo.

When a release is available, download its DMG from GitHub Releases, open it, and drag Tonal Island into Applications.

Launch the app and select your MIDI input. Use a connected MIDI keyboard or an available virtual MIDI source to see the notes and intervals you play.

Check the release notes for the required macOS version and supported Mac architectures. Alpha versions are early releases and may contain unfinished behavior.

If macOS reports a damaged app or an unverified developer, stop and report the release version and exact message. Official downloads must be signed and notarized; do not disable Gatekeeper.
