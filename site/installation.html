Tonal Island

Install Tonal Island

This first alpha uses a local ad-hoc signature and is not notarized by Apple. macOS may ask you to approve its first launch.

Try the demo

Apple Silicon · macOS 15.7 or later

  1. Download and open the DMG.
  2. Drag Tonal Island into Applications.
  3. Open Tonal Island from Applications.

If macOS blocks the first launch

  1. Try opening Tonal Island once, then dismiss the alert.
  2. Open System Settings → Privacy & Security.
  3. Find the message about Tonal Island and click Open Anyway, if offered.
  4. Confirm that you want to open it. macOS may request your Mac login password or Touch ID.

This creates an exception for this app. You do not need to disable Gatekeeper or run a Terminal command. Apple’s instructions.

Connect your keyboard

Select your MIDI input in the app, then play a few notes. Tonal Island displays the notes and intervals you play.

Check the download

Every GitHub Release includes its DMG, SHA256SUMS and version details. Check the release notes for compatibility and known limitations.

If macOS reports that the app is damaged or will harm your computer, stop and report the exact message and release version.
